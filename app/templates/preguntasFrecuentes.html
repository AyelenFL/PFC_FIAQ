Preguntas frecuentes

Todo lo que necesitás saber sobre FIAQ y la predicción de la capacidad antioxidante.

◈ ¿Qué es FIAQ?
FIAQ es una sitio web que predice la capacidad antioxidante de una molécula a partir de su notación SMILES, CAS o su nombre en ingles, usando un modelo de aprendizaje automático entrenado con datos experimentales.
◈ ¿Qué es la notación SMILES?
SMILES (Simplified Molecular Input Line Entry System) es una notación textual estándar que representa estructuras químicas como cadenas de caracteres. Por ejemplo, CC(=O)O es el Ácido Acético y CC(=O)Oc1ccccc1C(=O)O es la Aspirina.
◈ ¿Qué significan las categorías del resultado?
El modelo clasifica la capacidad antioxidante en tres niveles:
  • Alta — La molécula presenta una actividad antioxidante elevada respecto al conjunto de moléculas del modelo.
  • Media — La molécula presenta una actividad antioxidante moderada, intermedia entre las categorías extremas.
  • Baja — La molécula presenta una actividad antioxidante reducida en relación al resto de las moléculas del dominio de entrenamiento.
El porcentaje de confianza indica qué tan seguro está el modelo de esa clasificación.
◈ ¿Qué tan preciso es el modelo? ›
El modelo fue entrenado y validado con un conjunto de datos experimental de capacidad antioxidante medida por el método DPPH y normalizada con TEAC. La precisión varía según la similitud de la molécula consultada con las del conjunto de entrenamiento. El porcentaje de confianza que acompaña cada predicción es un buen indicador de la certeza del resultado.
◈ ¿Puedo ingresar el nombre de la molécula en lugar de SMILES? ›
Sí. El modelo también acepta el nombres en inglés de las moléculas (como "phenol", "caffeine", "quercetin"), como también el número CAS. El sistema internamente convierte el nombre o CAS a SMILES usando una base de datos química antes de realizar la predicción.
◈ ¿Qué descriptores moleculares usa el modelo? ›
El modelo utiliza descriptores fisicoquímicos calculados con RDKit, incluyendo propiedades como peso molecular, logP, número de donores y aceptores de puentes de hidrógeno, área de superficie polar (TPSA) y descriptores de anillos aromáticos, entre otros.
◈ ¿Las predicciones se guardan? ›
Actualmente las predicciones no se almacenan. Más adelante, se realizarán mejoras para permitir el almacenamiento de predicciones.
◈ ¿Cómo se interpreta el termómetro? ›
El termómetro tiene tres zonas: roja (Baja), amarilla (Media) y verde (Alta). El nivel de relleno dentro de cada zona representa la confianza del modelo — una predicción "Alta" con 95% de confianza llena casi toda la zona verde, mientras que una con 55% solo la llena a la mitad.
